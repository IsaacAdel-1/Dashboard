# Avaris Studio Dashboard

A dashboard for a real-estate video/photo editing studio: projects, clients, invoices, analytics and settings.
React 19 + Vite + Tailwind 4 + Recharts. All data is mock data loaded from a local JSON file — there's no backend.

## Run it

```bash
npm run dev      # app on http://localhost:5173
```

Regenerate the mock data (dates end today):

```bash
npm run seed
npm run seed -- --today=2026-11-08   # or end on a fixed date
```

Deployed on Vercel as a static site; `vercel.json` rewrites every route to `index.html` so refreshing a page like `/projects` works.

## Pages

| Route | What's there |
|---|---|
| `/` | KPIs vs previous period, revenue trend, project status, revenue by service, top clients, monthly goal, deadlines, recent projects, unpaid invoices |
| `/projects` | Searchable, filterable, sortable, paginated table. Click a cell to edit inline (Enter saves, Esc cancels), add / delete projects, export CSV |
| `/clients` | Client cards with computed revenue/projects/status, search, sort, filters, add client |
| `/clients/:id` | Client profile: KPIs, revenue by month, status split, projects, invoices, delete |
| `/invoices` | Collected / outstanding / overdue, invoiced vs collected chart, mark as paid, create invoice from a completed project, export CSV |
| `/analytics` | Revenue vs expenses, expenses by category, projects started, average value by service, team workload |
| `/settings` | Studio profile, billing defaults (currency, tax, payment terms, goal), service prices, light/dark theme |

The date range in the top bar drives the Dashboard and Analytics. Every chart has a table view (icon in the card header).

## Data

`src/data/company_database_sample.json` is generated by `scripts/seed.js` and imported by `src/services/api.js`,
a small in-memory data layer with the same `get / post / put / patch / remove` calls a REST client would have.
Reads wait ~400 ms so loading states show; creates, edits and deletes only change memory and reset on reload. Collections:
`settings`, `services`, `team`, `clients`, `projects`, `invoices`, `expenses`.
Projects and invoices reference clients by name. An invoice's status (Paid / Pending / Overdue) is not stored — it is worked out from `paidDate` and `dueDate`.

## Structure

```
src/
  data/                  the mock data (JSON)
  services/api.js        in-memory data layer over that JSON
  contexts/AppContext    date range, theme, studio settings, money formatter
  hooks/                 useFetch / useCollections, useSearch, useTable, useProjectsTable, useInvoicesSearching
  utils/                 date ranges, time-series buckets, formatting, constants
  components/ui/         Card, ChartCard, StatTile, StatusBadge, Modal, controls, states
  components/Charts/     Area, Bar, Line, Pie (donut) wrappers around Recharts
  pages/                 one file per route
```
